# Nexus Dashboard PRD

**Owner:** Founder
**Maturity baseline:** L3
**Release target:** L4

## Product purpose

The Dashboard is the authenticated ecosystem shell: it launches eligible
products and provides account, administrative, Cloud, and webmail surfaces.

## Verified current scope

- Catalog-based launch projection for released, stable, healthy user apps.
- Shell-native Mail and role-gated administrative/developer surfaces.
- Account and platform navigation.

## P1 requirements

- A unified notification centre that presents actionable product events.
- Clear user-facing availability state when a released app becomes unhealthy.
- Release visibility that does not expose internal platform services as apps.

## P2 requirements

- Cross-product health and release summary for authorised operators.
- Responsive and accessible launch, notification, and error states.

## Release acceptance

- Dashboard quality gate and catalog-contract tests pass.
- Nit passes for the affected release.
- Staging verifies launch, notification, and failure-state journeys.
- Founder records production approval and changelog entry.
