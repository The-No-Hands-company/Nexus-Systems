# Warrant canary

**Last updated:** 2026-10-16

## Statement

As of the date above, The No Hands Company (TNHC) states:

1. We have **not** received any government order, court order, subpoena, or other compulsory legal process requiring the disclosure of user data.
2. We have **not** received any request to introduce a backdoor, weakness, or surveillance capability into any TNHC system.
3. We have **not** been prohibited from disclosing any request for user data.
4. We have **not** been served with any national security letter or equivalent instrument.

## Scope

This canary covers the TNHC-operated Nexus Systems services reachable via tnhc.dev. It does **not** cover third-party providers (Cloudflare, Resend) — those maintain their own transparency reports.

## Freshness

This document is updated at least every **90 days**. If the date above is more than 90 days in the past, the canary should be treated as lapsed, which would indicate an inability to update it freely.

The git commit history of this file proves its currency. The current date is also published at `https://status.tnhc.dev/canary.json`.

## Legal context

TNHC is operated in Sweden. Swedish court orders are generally public; Swedish law does not provide for secret gag orders equivalent to US National Security Letters. This canary is published as an additional transparency measure consistent with the zero-retention and zero-disclosure design of the system.

See `docs/privacy/swedish-retention-law.md` for the full legal audit.
