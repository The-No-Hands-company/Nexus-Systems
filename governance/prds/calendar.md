# Nexus Calendar PRD

**Owner:** Founder
**Maturity baseline:** L2
**Release target:** L4

## Product purpose

Nexus Calendar provides private event management with explicit sharing and
public read-only links.

## Verified current scope

- Calendar view and event creation.
- Authenticated event access through the Dashboard proxy.
- Explicit viewer/editor sharing and revocable public read-only links.

## P1 requirements

- Edit and delete events.
- User-controlled event notifications.

## P2 requirements

- Shared calendars, invitations, and recurring events.
- Import/export and improved mobile experience.

## P3 requirements

- Resource booking and comprehensive time-zone support.

## Release acceptance

- Calendar API, frontend, and sharing/privacy tests pass.
- Staging verifies create, edit, delete, private access, and public-link
  revocation.
- Founder approves the release and records it in the changelog.
