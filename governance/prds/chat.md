# Nexus Chat PRD

**Owner:** Founder
**Maturity baseline:** L3
**Release target:** L4

## Product purpose

Nexus Chat is the privacy-first communication product for rooms, direct
messages, voice, and community interaction.

## Verified current scope

- Public chat service with channels, messaging, WebSocket gateway, voice, and
  federation capabilities registered in Nexus Cloud.
- Dashboard launch route and public Chat origin.

## P1 requirements

- Restore and continuously evidence healthy Cloud heartbeats.
- Define and test the core user journeys that establish L4 readiness.

## P2 requirements

- Product-level accessibility, responsive UX, and error-state acceptance
  criteria.

## P3 requirements

- Federation and advanced collaboration roadmap work once core reliability is
  evidenced.

## Release acceptance

- Chat runtime health reports green through Cloud before launch promotion.
- Relevant Chat tests, Nit, and staging smoke checks pass.
- Founder approves the release and records it in the changelog.
